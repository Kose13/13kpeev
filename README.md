# 🎵 BTV Music Debate Audio Files

Музика за музикален дебат на **BTV Новините** - комплект аудио файлове в WAV формат.

## 📁 Файлове

| Файл | Продължителност | Описание | Големина |
|------|----------------|----------|----------|
| `debate_intro_full.wav` | 30 секунди | Инспиращия интро с мелодия в C major и бас линия | 2.6 MB |
| `debate_transition.wav` | 10 секунди | Съспенс преход с низходяща синт мелодия | 882 KB |
| `debate_background_loop.wav` | 8 секунди | Фонова музика (loop) с меки акорди | 706 KB |
| `debate_outro_full.wav` | 20 секунди | Приключваща музика с възходяща мелодия | 1.8 MB |

## 🎧 Как да използвате

### 1. **Интро** (`debate_intro_full.wav`)
- **Кога:** В началото на предаването
- **Ефект:** Завлича вниманието с професионален новостен стил
- **Съвет:** Започнете с това, докато водещият представя темата

### 2. **Преход** (`debate_transition.wav`)
- **Кога:** Между рундовете на дебата
- **Ефект:** Създава напрежение и подчертава смяна на темата

### 3. **Фонова музика** (`debate_background_loop.wav`)
- **Кога:** По време на дискусията между участниците
- **Ефект:** Поддържа атмосферата, без да отвлича внимание
- **Съвет:** Пуснете я на **low volume** и я повтаряйте в цикъл

### 4. **Аутро** (`debate_outro_full.wav`)
- **Кога:** В края на предаването
- **Ефект:** Приятно затваряне с надеждна нота

## 🎛️ Технически детайли

- **Формат:** WAV (некомпресиран)
- **Честота:** 44.1 kHz (CD качество)
- **Канали:** Mono
- **Битова дълбочина:** 16-bit

## 📱 Съвместимост

Файловете могат да се пуснат с:
- **Windows:** Windows Media Player, VLC, Audacity
- **macOS:** QuickTime, VLC, iTunes, GarageBand
- **Linux:** VLC, Audacious, Rhythmbox
- **Мобилен:** Всички стандартни аудиоплеъри

## 🎬 Идеи за използване

1. **Миксирайте с глас** – Сложете гласа на водещия отгоре на музиката
2. **Добавете ефекти** – Реверб или delay за по-професионално звучене
3. **Настройте волюма** – Фоновата музика трябва да е по-тиха от гласовете
4. **Използвайте в видео** – Можете да ги сложите като саундтрак към видеоклипове
