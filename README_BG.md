## 🚀 Бърз старт (3 стъпки)

### 1️⃣ **Отворете MIDI файла**
- Файлът `60th_birthday_jazz.mid` е вече създаден
- Можете да го пуснете директно с:
  - Windows Media Player
  - VLC
  - MuseScore
  - Онлайн MIDI плеър

### 2️⃣ **Конвертирайте в MP3 и комбинирайте с посланието**
- **Опция А (Най-лесно):**
  - Отворете `60th_birthday_jazz.mid` в [Online-Convert](https://audio.online-convert.com/convert/midi-to-mp3)
  - Изтеглете MP3 файла
  - Отворете в Audacity и добавете `birthday_message_bg.mp3` в началото

- **Опция Б (С Audacity):**
  - Инсталирайте [Audacity](https://www.audacityteam.org/) (безплатен)
  - Файл → Импортирай → Audio → `60th_birthday_jazz.mid`
  - Файл → Импортирай → Audio → `birthday_message_bg.mp3`
  - Преместете посланието в началото
  - Добавете 2-3 секунди тишина след посланието

### 3️⃣ **Експортирайте и споделете**
- Файл → Експортирай → Audio → MP3
- Запазете като: `Честит_60_Рожден_Ден_Татко.mp3`
- **ГОТОВО!** 🎉
